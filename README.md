# 電腦大測溫習

雙擊 index.html 即可離線使用，請保留同層 images 資料夾。

題目來自「高三電腦大測筆試 A卷」及「B卷」，兩卷重複的題目只列一次，共 27 題：16 題選擇、7 題填空、2 題改錯、2 題程式題。每題標示出自哪份卷及題號。

- 複習：按 8 個知識點分組（網頁基礎、文字與標籤、列表、表格、圖片與路徑、超連結、CSS、完整網頁），每組先列「重點速記」。頂部以藍色卡片選題型，卡片顯示答對進度及錯題數；選了題型後，所有知識點中該題型的題目都會顯示，並按知識點分組。選擇題選答後直接核對；填空、改錯及程式題按「核對答案」。
- 使用指引：首頁列出建議溫習次序（複習 → 錯題重溫 → 模擬測試）；長頁面有「↑ 回到選擇」按鈕。填空題可按 Enter 核對。
- 解析：每題核對後（無論對錯）都會顯示解析；錯題重溫同樣按知識點分組。
- 模擬測試：先選 A卷、B卷（按原卷題目及題序）或隨機混合（從兩卷抽 10 題選擇、5 題填空、1 題改錯、1 題程式題）；交卷後顯示核對結果，不顯示分數。
- 錯題重溫：獨立入口、獨立作答紀錄；查看上次作答並重做。答對移出錯題簿，重新測試不清除錯題。
- 改錯題：使用 Word 中的題目程式碼，每題只有一個預先填好的編輯區，直接更正錯標籤或補回漏標籤。完成後核對；特殊結構列為待核對。
- 程式題：按 HTML5 宣告、文件結構、標題、段落、圖片、列表及超連結檢查。常見等效寫法可接受；其他標籤、自訂樣式等列為待核對，並提供自行確認按鈕。此功能是題目範圍的檢查，不是完整 HTML 驗證器。
- 學生程式碼僅以文字解析，不執行程式或載入其中的資源。
